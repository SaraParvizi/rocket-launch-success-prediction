Falcon Rocket Simulation Project

This repository contains a Python-based simulation project focused on analyzing the flight performance of Falcon rockets. The main goal of this project is to determine whether Falcon rockets successfully boost when launched under specific conditions, and to explore how flight parameters such as thrust, fuel, and acceleration impact rocket performance.

🎯 Project Goal

The goal of this project is to simulate Falcon rocket launches and evaluate their performance. Specifically, the project aims to answer the question:

Will a Falcon rocket successfully boost when launched under given conditions?

Additionally, the project analyzes how key factors such as thrust, fuel consumption, velocity, and acceleration affect flight outcomes.

📊 Project Overview

The project simulates rocket flights using physics-based models and tracks key parameters over time:

Parameter	Description
time	Simulation time steps
altitude	Rocket altitude at each time step
velocity	Rocket velocity at each time step
acceleration	Rocket acceleration at each time step
fuel_mass	Remaining fuel mass during flight
thrust	Engine thrust applied at each step

The simulation provides insights into the success of the rocket’s boost and highlights trends in flight performance.

🛠 Tools and Libraries Used

Programming Language: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn, SciPy

Environment: Google Colab, Jupyter Notebook

Techniques: Simulation, Data Analysis, Visualization

🔍 Key Findings

Successfully simulated Falcon rocket launches under different conditions.
